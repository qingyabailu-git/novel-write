# Novel Write

Write fiction through a selectable quick, standard, or heavy workflow.

## Select the workflow

Read references/writing-modes.md when choosing the mode.

- Use quick mode for a fragment, experiment, or low-risk draft that does not need persistence.
- Use standard mode for an ordinary scene or chapter that depends on existing continuity.
- Use heavy mode for a key scene, multiple chapters, a complex arc, or a task with high continuity risk.
- Follow an explicit user request for speed or review even when it differs from the default.

## Shared workflow

1. Determine the exact writing scope from the user. Do not assume that every request means write the next chapter.
2. Read the minimum necessary context: CREATOR.md, outline, progress, character state, relevant chapter group, recent chapters, and relevant lore.
3. For heavy mode, prepare a concise Context Plan covering scope, goal, required beats, character state, canon constraints, style constraints, and risks.
4. Draft only the requested range. Do not silently extend into later chapters or rewrite the premise.
5. If persistence is requested, create a new chapter with a full-file write or make a precise local edit. Do not use a broad replacement for a small change.
6. In standard or heavy mode, perform the review and repair steps in references/writing-modes.md.
7. After substantive writing, generate progress, character-state, world-state, and foreshadowing updates from the final text only.
8. Read back every changed file and verify that the intended content exists.

## Boundaries

- Keep stable canon in lore and current facts in state files.
- Do not update the long-term outline merely because a chapter was completed.
- Do not write a review report when the user only wants a quick draft.
- Do not claim a file was saved when the write or read-back failed.
- If file tools are unavailable, return the draft and clearly label any unsaved state patches.

## Output

Return the requested prose first. Add only a short persistence or state summary when it is useful or requested. Keep internal planning and reviewer dialogue hidden unless the user asks to see it.

Read references/writing-modes.md for mode-specific protocols and the reviewer contract.
