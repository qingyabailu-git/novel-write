# 小说自动流程状态

## 用途

`setting/workflow-state.md` 只记录小说创作自动流程的临时进度，帮助下一轮对话恢复阶段。它不是长期设定、章节正文、进度摘要或大纲，不能替代这些文件。

## 推荐字段

```markdown
# 小说创作自动流程状态

- 工作流：novel-workflow
- 项目根目录：
- 原始来源：
- 当前阶段：
- 已完成阶段：
- 待确认事项：
- 下一步动作：
- 最后一次用户确认：
- 最后更新时间：

## 已确认的本轮输入

- 

## 候选但未确认的内容

- 

## 流程分支与阻塞

- 
```

## 更新规则

- 用户确认后再把方案从“候选”移到“已确认”，并更新当前阶段。
- 只记录阶段、授权、路径、待办和恢复所需的摘要，不复制整章正文或完整 lore。
- 写入后读回文件，确认当前阶段、待确认事项和下一步动作没有丢失。
- 如果状态文件与实际章节文件冲突，以用户当前请求和实际正文为准；不要仅凭旧状态宣称某阶段已完成。
- 流程完成后保留最后状态，标注下一次可从“章节审查”或“章节续写”恢复。
