# Rewrite matrix

## Dialogue

Preserve the speaker's knowledge, relationship, intent, and voice. Change wording, rhythm, implication, or turn-taking only as requested.

## Plot

List the changed event and check all immediate consequences before writing. Flag downstream chapters that may now be false.

## Viewpoint

Preserve facts available to the new viewpoint. Remove knowledge the viewpoint character cannot access and add only observations that follow from the scene.

## Expansion

Add action, observation, sensory detail, or decision pressure that supports the existing event. Do not add a new subplot unless requested.

## Compression

Remove repetition and low-value explanation while preserving causality, character choices, reveals, and emotional turns.

## Voice and pacing

Use the active project style guide. Do not replace the story's personality with generic polished prose.

## State rule

If the final revision changes a story fact, update progress and character state from the final version. If it changes stable canon, propose a lore patch. Punctuation-only and wording-only edits do not require state updates.
