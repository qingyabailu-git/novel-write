# Novel Style

Maintain reusable prose behavior without putting plot facts into the style guide.

## Workflow

1. Read the current CREATOR.md and any existing style reference before changing them.
2. Separate project rules from reusable style: viewpoint, tense, voice, sentence rhythm, dialogue behavior, paragraphing, pacing, formatting, content boundaries, and forbidden habits belong in style; characters, events, places, and rules belong in lore.
3. If the user supplies reference prose, extract short, general principles and representative techniques. Do not save long raw excerpts, source-author names, or unrelated plot facts unless explicitly requested.
4. Show the proposed style guide or focused change before writing when the change is broad.
5. Write only the requested style file or CREATOR.md section and read it back.
6. When asked to test a style, apply it to a short user-provided or newly invented sample without changing canon files.

## Recommended style sections

- Narrative viewpoint and knowledge boundary.
- Voice, tone, and emotional distance.
- Sentence rhythm and paragraph length.
- Dialogue and action balance.
- Scene openings, transitions, and endings.
- Description density and sensory detail.
- Pacing and chapter length.
- Formatting rules.
- Content boundaries and expressions to avoid.

Read references/style-guide.md for the boundary between style, canon, and temporary scene context.
