# Continuation context contract

## Source priority

1. User's current request and explicit constraints.
2. Actual chapter prose.
3. CREATOR.md and confirmed lore.
4. Current character state and progress.
5. Long-term outline.
6. Chapter-group plan.

Use the outline and plan to understand direction, but use actual prose to determine what has already happened.

## Required continuity facts

Track time, place, viewpoint, body condition, knowledge, possessions, relationships, motivations, promises, secrets, unresolved hooks, and the last physical action.

For scenes involving movement, competition, tools, devices, or other procedural actions, also track the actor, target, object ownership, object location, and the operation required to move from one state to the next. Do not let a planned beat or a progress summary override what the latest prose actually proves.

## State write-back

After a substantive chapter:

- progress.md: latest chapter, concise summary, new immediate events, open hooks.
- character-states.md: current location, body, mind, goals, knowledge, possessions, relationships, and pending hooks.
- lore: only stable facts that should remain true beyond the current scene.

Do not put a future plan into a current-state field. Do not put temporary state into long-term lore.
