# Novel Continue

Continue from the actual latest chapter and current project state.

## Mandatory context

Before drafting, read:

1. setting/outline.md.
2. setting/progress.md.
3. setting/character-states.md.
4. The active chapter-group file, when one exists.
5. At least the previous two non-empty chapter files, or all available chapters when fewer than two exist.
6. Relevant lore entries.

Use actual chapter files to identify the latest chapter. Treat progress.md as a summary, not as proof that a chapter exists.

## Workflow

1. Determine the next chapter number and title from the existing naming convention.
2. Reconcile the previous ending, character state, unresolved hooks, and chapter-group purpose.
3. Draft only the requested chapter. Do not change the long-term outline.
4. Keep the chapter body as natural prose. Do not insert Markdown headings, lists, analysis, or a chapter title unless the project explicitly requires them.
5. Write the new chapter only when persistence is requested.
6. After the final prose revision, update progress.md and character-states.md from events that actually occur in the new chapter.
7. Propose a lore update only when a stable identity, relationship, ability, rule, place, faction, or item changed.
8. Read back the chapter and state files before reporting completion.

## Continuity checks

- Preserve time, place, body condition, knowledge, possessions, relationships, motivations, and speech patterns.
- Resolve or intentionally carry forward the previous chapter's hook.
- Complete the current chapter-group function without consuming later planned beats.
- Keep facts that were not known to the viewpoint character out of limited-POV narration.

Read references/context-contract.md for the source hierarchy and write-back rules.

Return the chapter first. Mention state and lore changes only after verifying them.
